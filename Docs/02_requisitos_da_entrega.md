# Requisitos da Entrega

## Itens obrigatórios
1. Modelo conceitual do data warehouse em PDF.
2. Configuração do ambiente analítico e dbt.
3. Transformação com dbt contendo:
   - documentação dos marts
   - testes de source
   - testes de primary key
   - teste de dados solicitado pelo CEO
   - código versionado no GitHub
4. Dashboard interativo respondendo às perguntas de negócio.
5. Vídeo de até 10 minutos apresentando o projeto.

## Itens opcionais
- Planejamento do projeto em PDF, com objetivos, stakeholders, riscos e contingências.

## Forma de entrega
- Link do GitHub em arquivo texto.
- Link do vídeo em arquivo texto.
- Modelo conceitual incluído na pasta de entrega.
